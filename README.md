# Web Security Labs

A practical collection of hands-on web application security
laboratories covering vulnerabilities, exploitation concepts,
and defensive techniques.

## Objectives

- Understand common web application vulnerabilities.
- Reproduce security issues in controlled local environments.
- Analyze their root causes.
- Implement and test defensive solutions.
- Document findings and security lessons.

## Laboratories

| # | Laboratory | Topics | Status |
|---|---|---|---|
| 01 | Race Condition | Concurrent requests, TOCTOU, database locking | In progress |

## Technologies

- PHP
- MySQL / MariaDB
- PDO

## Environment

The laboratories are designed to run in isolated local environments.

## Ethical Notice

All vulnerable examples are intentionally designed for educational
purposes. Only run them in environments you own or are authorized
to test.
